\chapter{Methodology}


This chapter explores the methodology adopted for the project development. For building the universal prober and the general steering technique for hallucination reduction, the datasets Belief Bank Facts \cite{BeliefBank}, Belief Bank Constraints \cite{BeliefBank} and Halu Eval \cite{Halueval} were used.
The first phase of the work involved dataset preparation and extraction of internal activations from the LLMs across all layers and each type of layer component (attention, MLP, hidden states). Subsequently, preliminary studies were conducted to evaluate the ability of each individual layer component to discriminate between true statements and hallucinations, in order to identify the most relevant layers and components. Regarding the construction of the universal prober the proposed solution \textbf{One-For-All} was compared with four alternative approaches based on linear and non-linear transformations of the activation space, with and without dimensionality reduction via autoencoder. 
Regarding the general steering technique for hallucination reduction, two different approaches were explored: the first one is based on the \textbf{TruthX} technique while the second one is an adaptation of the \textbf{SLiM} technique for the specific task of hallucination reduction.


\section{Dataset}

\subsection{Datasets Used}

\subsubsection{Belief Bank Facts}
This dataset was chosen as it can be used to detect \textit{Factual Hallucinations}.
The original BeliefBank facts cover 85 distinct entities belonging to the natural domain (animals and plants). Each instance in the dataset is a simple declarative sentence, such as \textit{An eagle is a bird} (True) or \textit{An eagle is a mammal} (False).
The truth labels (called \textit{silver labels}) were generated by the authors. 

The final dataset is composed of:
\begin{itemize}
    \item \textbf{Affirmative facts:} The original assertions extracted from BeliefBank (e.g., $fact$).
    \item \textbf{Negated facts:} For each present fact, its negated counterpart was synthetically generated (e.g., $\neg fact$), inverting the original truth label (from True to False and vice versa), in order to balance the classes and test model robustness.
\end{itemize}

with a total of 27,416 statements, of which 13,708 labeled as true (yes) and 13,708 as false (no), ensuring perfect balance between classes.

\subsubsection{Belief Bank Constraints}
This dataset was chosen as it can be used to detect \textit{Logical Inconsistencies}.
The original BeliefBank constraints were manually created by the authors and represent logical relationships between statements. 
The dataset is composed of:
\begin{itemize}
    \item \textbf{Positive implications:} Representation of logical implications between statements (if $A$ then $B$).
    \item \textbf{Mutual exclusions:} Representation of mutual exclusion constraints between statements (not both $A$ and $B$).
\end{itemize}
For each element, the negated version was also inserted to balance the classes. In total there are 25,756 statements to verify.

\subsubsection{HaluEval} This dataset was chosen to detect hallucinations in complex conversational contexts. Unlike simple facts, here each instance includes a context composed of dialogue history and supporting external knowledge.

The dataset is composed of: 
\begin{itemize} 
    \item \textbf{Correct Responses:} Factual responses consistent with the knowledge provided in the context (Right Response). 
    \item \textbf{Hallucinated Responses:} Synthetically generated responses that seem plausible but contain unverified or contradictory information with respect to the provided knowledge (Hallucinated Response). 
\end{itemize}

The final dataset is composed of 10,000 examples.

\subsection{Activation Dataset Creation}
Once the dataset of statements and their truthfulness labels was prepared, the next step was extracting internal activations from the models Llama-3.1-8B-Instruct \cite{LLama3} and gemma-2-9b-it \cite{Gemma2}. 
Each example is preceded by a prompt that is provided to the language model to guide its response.
For the Belief Bank Facts and Belief Bank Constraints datasets, the prompt used is as follows:
\begin{quote}
You are an expert in several domains. You'll be provided with a fact, and your task is to confirm or deny its truthfulness.
Do not provide any additional information or explanations.
Just answer only with yes or no.
Is the fact true? Fact: \{question\}.
Answer:
\end{quote}
where \{question\} is replaced with the specific statement to evaluate.

\noindent For the Halu Eval dataset, the prompt used is as follows:
\begin{quote}
    SYS\_FACT = "You are an expert in several domains. You’ll
be provided with a question, and your task is to
provide the correct answer. Do not provide any
additional information or explanations. Just
answer the question directly. Question: \{question\}. Answer:"

\end{quote}


Therefore, the LLM receives the prompt followed by the question as input and must respond with "yes" or "no" for the first two datasets, and with the answer to the question for the Halu Eval dataset.
For each statement in the dataset, the activations corresponding to all layers and components (attention, MLP, hidden states) of the models were recorded. These activations constitute the database on which the various probers for hallucination detection were trained. To verify whether the model responds correctly or hallucinates, a simple matching logic was used between the generated response and the truthfulness label associated with the statement in the dataset:
if the actual response (yes or no) is a substring (i.e., is contained) in the model's generated response, then the statement is considered true (non-hallucination); otherwise it is considered false (hallucination).

\begin{itemize}

\end{itemize}
Like Llama-3.1-8B-Instruct, Gemma-2-9B-IT was also optimized for dialogue and instruction following through SFT and DPO.

\subsection{Study of Individual Layer Components}

To evaluate the discriminative ability of the different layer components (attention, MLP, hidden states) of the various LLMs in detecting hallucinations, systematic experiments were conducted on each layer and activation type. In particular, for each layer and component, the corresponding activations were extracted and used as input to train a Logistic Regression classifier, with the goal of distinguishing between true statements and hallucinations.

The experimental pipeline includes:
\begin{enumerate}
\item Extraction of activations for each layer and component (attention, MLP, hidden) from the models over the entire dataset.
\item Undersampling and splitting of the dataset into training and test sets, keeping the same split for all experiments.
\item Normalization of activations using StandardScaler.
\item Training of a Logistic Regression classifier for each layer/component combination.
\item Evaluation of performance through accuracy metrics.
\end{enumerate}

The results show that some components and layers are particularly effective in discriminating hallucinations, highlighting the presence of specific informative patterns in the internal activations of models

\section{Methodologies for Building the Universal Prober}
This section describes the four methodological approaches adopted to "build a baseline" for the universal prober capable of detecting hallucinations in language models and the methodological approach to build the universal prober itself, called \textbf{One-For-All}.

Experiment reproducibility and the use of the same data sets for all methods are guaranteed by setting a common random seed and using deterministic next token sampling in LLMs.


Two dataset management modes are distinguished:
\begin{itemize}
\item \textbf{Concordant Dataset (for Alignment):} Only examples where Trainer and Tester agree on classification (same label) are selected. Undersampling is applied to these to balance classes. This is essential for learning a coherent mapping between tester and trainer.
\item \textbf{Independent Dataset (for Probing/Autoencoder/Encoder):} Undersampling is applied to balance classes specifically on the labels of the model in question (Trainer or Tester), independently from the other model. This maximizes the amount of data available for training robust models.
\end{itemize}

\subsection{FullLinear Approach}
The first approch to build a baseline for the universal prober, is a linear approach. In this scenario, the internal activations of the models, extracted from the selected layers and components, were used to train and evaluate a Logistic Regression classifier. The objective is to verify performance using only linear methods.

\end{itemize}

\subsection{AdapterMLP Approach}

In this approach, a non-linear adaptation procedure of the tester model's latent space towards the trainer model's space is explored using a low-dimensional alignment network (called AlignmentNetwork or AdapterMLP). The objective is to observe whether introducing a non-linear component in the alignment improves universal prober performance, while maintaining a linear classifier (Logistic Regression) on the trainer model.

Some key characteristics of the AlignmentNetwork include: 
\begin{itemize}
\item \textbf{Zero-init:} the last layers of the decompression are initialized to zero so that the network starts close to a linear identity transformation, allowing the non-linear component to emerge only if truly useful.
\item \textbf{MixedLoss:} the loss function combines Mean Squared Error (MSE) and a component based on cosine similarity:
\[
\mathcal{L} = \alpha \cdot \mathrm{MSE}(\hat{y}, y) + \beta \cdot (1 - \text{cosine\_sim}(\hat{y}, y))
\]
with configurable weights $\alpha$ (MSE) and $\beta$ (cosine) to balance fidelity and angular alignment.
\end{itemize}

where MSE is defined as:
\[
\mathrm{MSE}(\hat{y}, y) = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2
\]
and cosine similarity is defined as:
\[
\text{cosine\_sim}(\hat{y}, y) = \frac{\hat{y} \cdot y}{\|\hat{y}\| \|y\|} = \frac{\sum_{i=1}^{N} \hat{y}_i y_i}{\sqrt{\sum_{i=1}^{N} \hat{y}_i^2} \sqrt{\sum_{i=1}^{N} y_i^2}}
\]

\subsubsection{Experimental Pipeline}
The experimental pipeline in figure \ref{fig:hybrid-pipeline} first involves training a probe (Logistic Regression) on the trainer's activation space using the entire balanced trainer training set; this classifier will remain fixed. Subsequently, the AlignmentNetwork is trained to project tester activations into the trainer's space, minimizing the loss between projected activations and original trainer activations using the balanced concordant activations dataset. Finally, the tester's test activations are projected via the AlignmentNetwork and classified using the probe trained on the trainer.

BCEWithLogitsLoss is defined as:
\[

\]
where $\sigma(x)$ is the sigmoid function:
\[
\sigma(x) = \frac{1}{1 + e^{-x}}
\]

\subsubsection{Experimental Pipeline}
The experimental pipeline in figure \ref{fig:non-linear-reduced-pipeline} first involves training two autoencoders: one on the trainer's activations and the other on the tester's, thus obtaining two distinct latent spaces. Subsequently, the activations are encoded in their respective latent spaces. An MLP classifier is trained on the trainer's latent space. Then, an Alignment Network is trained that maps the tester's latent representations to the trainer's latent space using concordant data. Finally, for evaluation, the MLP classifier trained on the trainer is used to classify the tester's representations after alignment and dimensionality reduction.

\subsection{One-For-All Approach (Frozen Head)}

One-For-All represents the proposed \textbf{Universal Prober}: a two-phase procedure is adopted, designed to evaluate the transferability of a decision function (the classification \emph{head}) between two different models while keeping the same head and adapting only the tester's encoder. Unlike previous approaches, this method does not require concordant data for alignment but uses independent balanced datasets for each model.

\subsubsection{Experimental pipeline}
The experimental pipeline in Figure \ref{fig:OfA-pipeline} first involves joint training of the encoder and classification head on the trainer model's activation space (End-to-End). Once training is complete, the head is frozen (\emph{Frozen Head}) to keep the learned decision function unchanged. Subsequently, a new encoder is trained on the tester model's activation space: the output of this new encoder is passed to the trainer's frozen head, and the loss is calculated directly on the classification error (BCEWithLogitsLoss). In this way, the tester learns to produce latent representations compatible with the trainer's "head".

\section{Methodology for hallucination mitigation steering}
This section describess the methodological approach to build a universal steering mechanism for hallucination mitigation in language models. In particular two different steering techniques are explored: \textbf{TruthX} and \textbf{SLiM}. The first one is a known technique in literature to reduce hallucinations in LLMs, while the second one is an adaptation of the original SLiM implementation, that was originally developed to steer the style of LLM's answers, to the hallucination mitigation task.

In both cases the dataset is dived in two subsets:
\begin{itemize}
\item \textbf{Training Dataset:} subset of the original dataset used train the steering mechanism. 80\% of the original dataset is used to train the steering mechanism, while the remaining 20\% is used as validation set to perform early stopping during training.
\item \textbf{Evaluation Dataset:} subset of the original dataset used to evaluate the performance of the steering mechanism. The evaluation dataset is completely unseen during training and is used to evaluate the generalization ability of the steering mechanism.
\end{itemize}

\subsection{TruthX Steering Technique}

TruthX is a steering technique designed to reduce hallucinations in LLMs by operating directly on the internal representations of the model during inference. The core idea is based on \textbf{Disentangled Representation Learning} \cite{DisentangledRepresentationLearning}: the internal activations of each layer are decomposed into two distinct latent spaces: a \textbf{semantic space} that captures the meaning/content of the statement and a \textbf{truthful space} that encodes its veracity. By manipulating only the truthful component while leaving the semantic content untouched, TruthX can steer the model's output towards more truthful generations without altering the intended meaning.

The TruthX pipeline involves three main phases:
\begin{enumerate}
    \item \textbf{Training of the Autoencoder} on paired activations (truthful/hallucinated) to learn the disentangled representation;
    \item \textbf{Computation of steering vectors} ($\delta$) and probing-based selection of the most informative layers;
    \item \textbf{Inference-time editing} of the internal representations via forward hooks on the selected modules.
\end{enumerate}

\subsubsection{Dataset Preparation: Paired Activations}

TruthX requires \textbf{paired samples}: for each statement, a truthful version and a hallucinated version sharing the same semantic content are needed.

For each pair (see tab. \ref{tab:datasets-pairs}), the internal activations of the LLM are extracted at \textbf{all layers} and for \textbf{both module types} (attention and MLP/FFN), storing the activation of the last input token. This produces a set of \textit{virtual layers}: for a model with $L$ physical layers, there are $2L$ virtual layers (one for each attention and one for each MLP module). True instances are assigned even instance IDs while false instances receive odd IDs, enabling deterministic pairing.

\subsubsection{Autoencoder Architecture}

The autoencoder is composed of three sub-networks:

\begin{itemize}
    \item \textbf{Semantic Encoder ($\mathrm{SemEnc}$):} maps the input activation $\mathbf{x} \in \mathbb{R}^{d}$ (where $d$ is the model's hidden size, e.g. 4096 for Llama-3-8B) into a semantic latent representation $\mathbf{h}_{\mathrm{sem}} \in \mathbb{R}^{1024}$. Architecture: $d \to 2048 \to 1024$, with LayerNorm and LeakyReLU after each linear layer.
    \item \textbf{Truthful Encoder ($\mathrm{TruthEnc}$):} maps the input activation into a truthful latent representation $\mathbf{h}_{\mathrm{truth}} \in \mathbb{R}^{1024}$, L2-normalized. Same architecture as the Semantic Encoder but with L2 normalization on the output.
    \item \textbf{Decoder ($\mathrm{Dec}$):} reconstructs the original activation from the combined latent representation. Architecture: $1024 \to 2048 \to d$.
\end{itemize}

The combination of semantic and truthful representations is performed via a \textbf{Cross-Attention} mechanism:
\[
\mathbf{z} = \mathbf{h}_{\mathrm{sem}} + \mathrm{Attn}(\mathbf{h}_{\mathrm{sem}},\; \mathbf{h}_{\mathrm{truth}},\; \mathbf{h}_{\mathrm{truth}})
\]
where $\mathrm{Attn}$ is a single-head multi-head attention module. The final reconstruction is:
\[
\hat{\mathbf{x}} = \mathrm{Dec}(\mathbf{z})
\]

\subsubsection{Loss Function}

The total training loss combines four components following the TruthX paper:
\[
\mathcal{L} = w_r \cdot \mathcal{L}_{\mathrm{recon}} + w_c \cdot \mathcal{L}_{\mathrm{sem}} + w_t \cdot \mathcal{L}_{\mathrm{truth}} + w_e \cdot \mathcal{L}_{\mathrm{edit}}
\]

\paragraph{Reconstruction Loss ($\mathcal{L}_{\mathrm{recon}}$, Eq. 3):}
Ensures the autoencoder can faithfully reconstruct the original activations:
\[
\mathcal{L}_{\mathrm{recon}} = \frac{1}{2} \left( \mathrm{MSE}(\hat{\mathbf{x}}_{\mathrm{pos}}, \mathbf{x}_{\mathrm{pos}}) + \mathrm{MSE}(\hat{\mathbf{x}}_{\mathrm{neg}}, \mathbf{x}_{\mathrm{neg}}) \right)
\]

\paragraph{Semantic Contrastive Loss ($\mathcal{L}_{\mathrm{sem}}$, Eq. 6):}
Forces the Semantic Encoder to produce similar representations for paired samples (same semantic content, opposite veracity) while separating semantically different samples:
\[
\mathcal{L}_{\mathrm{sem}} = \mathrm{CTR}(\mathbf{h}_{\mathrm{sem}}^{\mathrm{pos}}, \{\mathbf{h}_{\mathrm{sem}}^{\mathrm{neg}}\}, H_{\mathrm{sem}}^{\mathrm{pos}} \setminus \{\mathbf{h}_{\mathrm{sem}}^{\mathrm{pos}}\}) + \mathrm{CTR}(\mathbf{h}_{\mathrm{sem}}^{\mathrm{neg}}, \{\mathbf{h}_{\mathrm{sem}}^{\mathrm{pos}}\}, H_{\mathrm{sem}}^{\mathrm{neg}} \setminus \{\mathbf{h}_{\mathrm{sem}}^{\mathrm{neg}}\})
\]
where $\mathrm{CTR}(\mathbf{s}, S^+, S^-)$ is the contrastive function:
\[
\mathrm{CTR}(\mathbf{s}, S^+, S^-) = -\log \frac{\sum_{\mathbf{s}' \in S^+} \exp\!\big(\mathrm{sim}(\mathbf{s}, \mathbf{s}') / \tau\big)}{\sum_{\mathbf{s}' \in S^+ \cup S^-} \exp\!\big(\mathrm{sim}(\mathbf{s}, \mathbf{s}') / \tau\big)}
\]
with temperature $\tau = 0.1$ and cosine similarity $\mathrm{sim}(\cdot, \cdot)$.

\paragraph{Truthful Contrastive Loss ($\mathcal{L}_{\mathrm{truth}}$, Eq. 5):}
Separates truthful representations of positive samples from those of negative samples in the truthful latent space:
\[
\mathcal{L}_{\mathrm{truth}} = \mathrm{CTR}(\mathbf{h}_{\mathrm{truth}}^{\mathrm{pos}}, H_{\mathrm{truth}}^{\mathrm{pos}}, H_{\mathrm{truth}}^{\mathrm{neg}}) + \mathrm{CTR}(\mathbf{h}_{\mathrm{truth}}^{\mathrm{neg}}, H_{\mathrm{truth}}^{\mathrm{neg}}, H_{\mathrm{truth}}^{\mathrm{pos}})
\]

\paragraph{Editing Loss ($\mathcal{L}_{\mathrm{edit}}$, Eq. 10):}
Ensures that swapping the truthful component between a positive and a negative sample yields a reconstruction close to the opposite sample:
\[
\mathbf{x}^{\mathrm{pos} \to \mathrm{neg}} = \mathrm{Dec}\!\left(\mathbf{h}_{\mathrm{sem}}^{\mathrm{pos}} + \mathrm{Attn}(\mathbf{h}_{\mathrm{sem}}^{\mathrm{pos}}, \mathbf{h}_{\mathrm{truth}}^{\mathrm{neg}}, \mathbf{h}_{\mathrm{truth}}^{\mathrm{neg}})\right)
\]
\[
\mathbf{x}^{\mathrm{neg} \to \mathrm{pos}} = \mathrm{Dec}\!\left(\mathbf{h}_{\mathrm{sem}}^{\mathrm{neg}} + \mathrm{Attn}(\mathbf{h}_{\mathrm{sem}}^{\mathrm{neg}}, \mathbf{h}_{\mathrm{truth}}^{\mathrm{pos}}, \mathbf{h}_{\mathrm{truth}}^{\mathrm{pos}})\right)
\]
\[
\mathcal{L}_{\mathrm{edit}} = \mathrm{MSE}(\mathbf{x}^{\mathrm{pos} \to \mathrm{neg}},\, \mathbf{x}_{\mathrm{neg}}) + \mathrm{MSE}(\mathbf{x}^{\mathrm{neg} \to \mathrm{pos}},\, \mathbf{x}_{\mathrm{pos}})
\]

\subsubsection{Training Procedure}

The training procedure processes all $2L$ virtual layers per epoch. For each virtual layer, the paired activations (positive and negative) are loaded and organized into structured batches where \texttt{batch\_pos[i]} and \texttt{batch\_neg[i]} always form a semantically aligned pair. The dataset is split into 80\% training and 20\% validation using a global permutation that ensures each pair remains entirely in one set.

The optimizer used is \textbf{AdamW} with a \textbf{Cosine Annealing with Warm Restarts} learning rate scheduler, preceded by a linear warmup phase. Early stopping on validation loss with configurable patience prevents overfitting.

\subsubsection{Steering Vector Computation and Layer Selection}

After training, the autoencoder is used to compute the \textbf{steering vectors} for each virtual layer. For all paired activations, the Truthful Encoder produces the truthful representations $\mathbf{h}_{\mathrm{truth}}^{\mathrm{pos}}$ and $\mathbf{h}_{\mathrm{truth}}^{\mathrm{neg}}$. The positive and negative centers are computed as the means:
\[
\bar{H}_{\mathrm{truth}}^{\mathrm{pos}} = \frac{1}{N} \sum_{i=1}^{N} \mathbf{h}_{\mathrm{truth},i}^{\mathrm{pos}}, \qquad \bar{H}_{\mathrm{truth}}^{\mathrm{neg}} = \frac{1}{N} \sum_{i=1}^{N} \mathbf{h}_{\mathrm{truth},i}^{\mathrm{neg}}
\]
The steering vector $\boldsymbol{\delta}$ for each virtual layer is (Eq. 12):
\[
\boldsymbol{\delta} = \bar{H}_{\mathrm{truth}}^{\mathrm{pos}} - \bar{H}_{\mathrm{truth}}^{\mathrm{neg}}
\]

To select which modules to edit during inference, a \textbf{probing-based layer selection} (Eq. 15) is employed. For each virtual layer, a simple probing classifier is evaluated:
\[
\mathrm{Probe}(\mathbf{x}) = \begin{cases} \mathrm{pos} & \text{if } \mathrm{sim}(\mathbf{h}_{\mathrm{truth}}, \bar{H}_{\mathrm{truth}}^{\mathrm{pos}}) \ge \mathrm{sim}(\mathbf{h}_{\mathrm{truth}}, \bar{H}_{\mathrm{truth}}^{\mathrm{neg}}) \\ \mathrm{neg} & \text{otherwise} \end{cases}
\]
The virtual layers are ranked by probing accuracy and the \textbf{top-$k$} modules are selected for editing. For instance, for a 32-layer LLM with $k=10$, TruthX selects the 10 modules with the highest probing accuracy out of the total 64 modules (32 attention + 32 MLP).


\subsubsection{Inference-Time Editing}
\label{sec:truthx-inference}

During inference, TruthX modifies the model's internal representations in real-time by registering \textbf{forward hooks} on the selected top-$k$ modules. For each selected module, when a forward pass produces an activation $\mathbf{X}$, the editing procedure is:

\begin{enumerate}
    \item Extract the truthful representation: $\mathbf{h}_{\mathrm{truth}} = \mathrm{TruthEnc}(\mathbf{X})$
    \item Compute the positive and negative edited reconstructions by shifting the truthful representation along $\boldsymbol{\delta}$:
    \[
    \hat{\mathbf{X}}_{\mathrm{pos}} = \mathrm{Dec}\!\left(\mathbf{h}_{\mathrm{sem}} + \mathrm{Attn}\!\left(\mathbf{h}_{\mathrm{sem}},\; F_{\mathrm{norm}}(\mathbf{h}_{\mathrm{truth}} + \boldsymbol{\delta}),\; F_{\mathrm{norm}}(\mathbf{h}_{\mathrm{truth}} + \boldsymbol{\delta})\right)\right)
    \]
    \[
    \hat{\mathbf{X}}_{\mathrm{neg}} = \mathrm{Dec}\!\left(\mathbf{h}_{\mathrm{sem}} + \mathrm{Attn}\!\left(\mathbf{h}_{\mathrm{sem}},\; F_{\mathrm{norm}}(\mathbf{h}_{\mathrm{truth}} - \boldsymbol{\delta}),\; F_{\mathrm{norm}}(\mathbf{h}_{\mathrm{truth}} - \boldsymbol{\delta})\right)\right)
    \]
    where $F_{\mathrm{norm}}$ denotes L2 normalization.
    \item Compute the final editing direction:
    \[
    \boldsymbol{\Delta} = \hat{\mathbf{X}}_{\mathrm{pos}} - \hat{\mathbf{X}}_{\mathrm{neg}}
    \]
    \item Apply the steering:
    \[
    \mathbf{X}' = \mathbf{X} + \alpha \cdot \boldsymbol{\Delta}
    \]
    where $\alpha$ is the \texttt{edit\_strength} parameter controlling the intensity of the intervention.
\end{enumerate}

The editing is applied in a fully differentiable manner, modifying the activations before they are passed to the next layer. 

\subsubsection{Cross-Model TruthX via Alignment}

A key contribution of this work is the generalization of TruthX to a \textbf{cross-model} setting, where the autoencoder and steering vectors are trained on a \textit{trainer model} (e.g., Gemma-2-9B-IT) and applied to a different \textit{target model} (e.g., Llama-3.1-8B-Instruct). This requires solving two problems: (i) identifying \textit{which} layers of the two models are structurally most comparable, and (ii) learning a linear map between their activation spaces.

\paragraph{Layer Selection via Linear CKA.}
Since the two models may have different numbers of layers and different hidden dimensions, a direct layer-to-layer correspondence cannot be assumed. The Procrustes aligner determines this correspondence automatically using \textbf{Linear CKA} (Centered Kernel Alignment), a similarity index between representation matrices that is invariant to orthogonal transformations and isotropic scaling.

Given two centered activation matrices $\mathbf{X}_c \in \mathbb{R}^{n \times d_x}$ and $\mathbf{Y}_c \in \mathbb{R}^{n \times d_y}$, Linear CKA is defined as:
\[
\mathrm{CKA}(\mathbf{X}, \mathbf{Y}) = \frac{\|\mathbf{X}_c^T \mathbf{Y}_c\|_F^2}{\|\mathbf{X}_c^T \mathbf{X}_c\|_F \cdot \|\mathbf{Y}_c^T \mathbf{Y}_c\|_F}
\]
CKA takes values in $[0, 1]$, where 1 indicates identical (up to rotation/scaling) representations and 0 indicates orthogonal ones.

The layer selection procedure is as follows:
\begin{enumerate}
    \item The \textbf{top-1 target module} is identified via the probing-based layer selection (see Section above): this is the module of the target model whose truthful representations best separate true and false statements.
    \item For each layer of the \textbf{trainer model} of the same module type (attention or MLP), Linear CKA is computed between the trainer layer's activations and the target's top-1 module activations, on a shared set of instances.
    \item The \textbf{trainer layer that maximises CKA} with the target top-1 is selected as the alignment anchor. Intuitively, this is the trainer layer whose representation geometry most resembles the target layer.
\end{enumerate}

\paragraph{Procrustes Aligner.}
Once the layer pair is identified, the \textbf{Orthogonal Procrustes} method finds the optimal rotation (with scale and translation) that maps one activation space into the other, minimising the Frobenius-norm reconstruction error. Given centered activation matrices $\mathbf{X}_c$ (source) and $\mathbf{Y}_c$ (target), the SVD of their cross-covariance is computed:
\[
\mathbf{U}\,\boldsymbol{\Sigma}\,\mathbf{V}^T = \mathrm{SVD}\!\left(\mathbf{X}_c^T\, \mathbf{Y}_c\right)
\]
The optimal rotation and scale factor are:
\[
\mathbf{R} = \mathbf{U}\mathbf{V}^T, \qquad
s = \frac{\sum_i \sigma_i}{\|\mathbf{X}_c\|_F^2}
\]
so that the full affine transformation is:
\[
\hat{\mathbf{Y}} = \mathbf{X}\,\mathbf{A} + \mathbf{b}, \qquad \mathbf{A} = s\cdot\mathbf{R}, \qquad \mathbf{b} = \bar{\mathbf{y}} - \bar{\mathbf{x}}\,\mathbf{A}
\]
where $\bar{\mathbf{x}}$ and $\bar{\mathbf{y}}$ are the empirical means of the source and target activations. By constraining the map to be a scaled orthogonal transformation, Procrustes preserves angular relationships between representations, unlike unconstrained linear regression.

Two maps are fitted independently:
\begin{itemize}
    \item $\mathbf{A}_{\mathrm{t \to tr}},\, \mathbf{b}_{\mathrm{t \to tr}}$: \textbf{Target $\to$ Trainer} (pre-alignment);
    \item $\mathbf{A}_{\mathrm{tr \to t}},\, \mathbf{b}_{\mathrm{tr \to t}}$: \textbf{Trainer $\to$ Target} (post-alignment).
\end{itemize}

\paragraph{Cross-Model Inference Pipeline.}
During inference on the target model, TruthX editing proceeds as follows for each selected module:
\begin{enumerate}
    \item \textbf{Pre-alignment:} the target model's activation $\mathbf{x}_{\mathrm{target}} \in \mathbb{R}^{d_{\mathrm{target}}}$ is mapped into the trainer's space:
    \[
    \tilde{\mathbf{x}} = \mathbf{x}_{\mathrm{target}}\,\mathbf{A}_{\mathrm{t \to tr}} + \mathbf{b}_{\mathrm{t \to tr}}
    \]
    \item \textbf{TruthX editing:} $\tilde{\mathbf{x}}$ is processed by the trainer's autoencoder to produce the edited activation $\tilde{\mathbf{x}}'$ (as described in Section~\ref{sec:truthx-inference}).
    \item \textbf{Post-alignment:} the edited activation is mapped back into the target model's space:
    \[
    \mathbf{x}'_{\mathrm{target}} = \tilde{\mathbf{x}}'\,\mathbf{A}_{\mathrm{tr \to t}} + \mathbf{b}_{\mathrm{tr \to t}}
    \]
\end{enumerate}
This symmetrical pre/post-alignment strategy ensures that the TruthX intervention operates entirely in the trainer's representation space, while the final output is expressed in the target model's native space.


\subsection{SLiMTruth Steering Technique}
SLiMTruth is an adaptation of the \textbf{State-wise Linear Modulation (SLiM)} framework, originally designed to steer the stylistic attributes of LLM outputs, to the task of hallucination mitigation. The core idea is to apply a lightweight \textbf{FiLM} (Feature-wise Linear Modulation) transformation to the hidden representations of a single transformer layer, conditioned on an external state vector, so as to push the model's internal representations toward more truthful generations.

Unlike TruthX, which decomposes activations into disentangled semantic/truthful latent spaces via an autoencoder, SLiMTruth operates directly in the model's native hidden space: it learns a \textit{scale} and a \textit{shift} vector that multiplicatively and additively modulate the layer output, respectively. This results in an extremely parameter-efficient intervention (only the SLiM modules are trained; the base LLM remains completely frozen).

The SLiMTruth pipeline involves three main phases:
\begin{enumerate}
    \item \textbf{Dataset Preparation}: construction of paired (truthful/hallucinated) samples from the same datasets used for TruthX (see Tab.~\ref{tab:datasets-pairs});
    \item \textbf{Training} of the SLiM modules with a hybrid loss combining cross-entropy, contrastive, and regularization objectives;
    \item \textbf{Inference-time modulation} via a forward hook on the target layer.
\end{enumerate}

\subsubsection{Dataset Preparation: Paired Samples}

SLiMTruth uses the same paired datasets described in Table~\ref{tab:datasets-pairs}.

\noindent Crucially, during training \textbf{both positive and negative samples receive the same state value} $s = 1.0$. The SLiM transformation is therefore identical for both classes: scale and shift act as content-dependent feature selectors, and the model must learn to separate truthful from hallucinated representations based on the \textit{content} of the hidden states, not on label information leaked via the state.

In particular SLiM is trained on a single target layer, which can be provided as an argument. In particular, for these experiments for each pair (model,dataset) the best layer from premilinar analysis was selected as target layer for SLiMTruth training. See figures

\subsubsection{SLiMTruth Architecture}

SLiMTruth wraps a frozen LLM and injects a FiLM-like modulation at the output of a single user-specified transformer layer (the \textit{target layer}). The architecture is composed of three lightweight modules:

\paragraph{State Projector (\texttt{StateBlock}).}
Maps the scalar state $s \in \mathbb{R}$ into the model's hidden space:
\[
\mathbf{p} = \mathrm{LayerNorm}\!\big(\mathrm{ReLU}(\mathbf{W}_s \cdot s + \mathbf{b}_s)\big) \in \mathbb{R}^{d}
\]
where $d$ is the hidden size of the LLM (e.g.\ 4096 for Llama-3.1-8B). The projector has architecture $1 \to d$ with ReLU activation and LayerNorm.

\paragraph{Low-Rank Scale (\texttt{LowRankLinear}).}
Computes the multiplicative modulation vector via a low-rank factorization:
\[
\boldsymbol{\gamma} = \tanh\!\big(\mathbf{W}_{\mathrm{up}}^{\gamma}\;(\mathbf{W}_{\mathrm{down}}^{\gamma}\;\mathbf{p}) + \mathbf{b}^{\gamma}\big) \in \mathbb{R}^{d}
\]
where $\mathbf{W}_{\mathrm{down}}^{\gamma} \in \mathbb{R}^{r \times d}$ and $\mathbf{W}_{\mathrm{up}}^{\gamma} \in \mathbb{R}^{d \times r}$, with $r$ the rank of the factorization (default $r = 32$). This reduces the parameter count from $d^2$ to $r \cdot (2d)$.

\paragraph{Low-Rank Shift (\texttt{LowRankLinear}).}
Computes the additive modulation vector with the same architecture:
\[
\boldsymbol{\beta} = \tanh\!\big(\mathbf{W}_{\mathrm{up}}^{\beta}\;(\mathbf{W}_{\mathrm{down}}^{\beta}\;\mathbf{p}) + \mathbf{b}^{\beta}\big) \in \mathbb{R}^{d}
\]

Both scale and shift are initialized to produce \textbf{zero output at initialization} ($\mathbf{W}_{\mathrm{up}}$ initialized to zero), so that the initial modulation is the identity transformation and training starts from the unmodified model behavior.

\paragraph{FiLM Modulation.}
Given the hidden state $\mathbf{h} \in \mathbb{R}^{B \times S \times d}$ at the output of the target layer, the modulation is:
\[
\boldsymbol{\delta} = \mathbf{h} \odot \boldsymbol{\gamma} + \boldsymbol{\beta}
\]
\[
\mathbf{h}' = \mathbf{h} + \alpha \cdot \boldsymbol{\delta}
\]
where $\odot$ denotes element-wise multiplication, and $\alpha \in [0, 1]$ is the \texttt{steering strength} parameter that controls the intensity of the intervention. When $\alpha = 0$ the output is unmodified; when $\alpha = 1$ the full modulation is applied. The $\tanh$ activation bounds $\boldsymbol{\gamma}, \boldsymbol{\beta} \in (-1, 1)$, preventing unbounded perturbations.

\subsubsection{Loss Function}

The training loss combines three components in a single hybrid objective:
\[
\mathcal{L} = \lambda_{\mathrm{ce}} \cdot \mathcal{L}_{\mathrm{CE}} + \lambda_{\mathrm{nce}} \cdot \mathcal{L}_{\mathrm{InfoNCE}} + \lambda_{\mathrm{reg}} \cdot \mathcal{L}_{\mathrm{Reg}}
\]

\paragraph{Cross-Entropy Loss ($\mathcal{L}_{\mathrm{CE}}$).}
Standard causal language modeling loss on the next-token prediction, computed separately on positive and negative samples and averaged:
\[
\mathcal{L}_{\mathrm{CE}} = \frac{1}{2}\Big(\mathrm{CE}(\hat{\mathbf{y}}_{\mathrm{pos}},\, \mathbf{y}_{\mathrm{pos}}) + \mathrm{CE}(\hat{\mathbf{y}}_{\mathrm{neg}},\, \mathbf{y}_{\mathrm{neg}})\Big)
\]
where $\hat{\mathbf{y}}$ are the logits produced by the modulated model on the steered hidden states. By default, the CE loss is computed \textbf{only on the answer tokens}, so that the model is not penalized for the prompt generation and focuses on steering the answer.

\paragraph{InfoNCE Contrastive Loss ($\mathcal{L}_{\mathrm{InfoNCE}}$).}
Adapted from TruthX's truthful contrastive loss. Given a batch of $N$ paired samples, the representations $\mathbf{h}_{\mathrm{pos},i}, \mathbf{h}_{\mathrm{neg},i} \in \mathbb{R}^{d}$ are L2-normalized and the bidirectional InfoNCE loss is:
\[
\mathcal{L}_{\mathrm{InfoNCE}} = \mathrm{CTR}(\mathbf{h}_{\mathrm{pos}},\, H_{\mathrm{pos}},\, H_{\mathrm{neg}}) + \mathrm{CTR}(\mathbf{h}_{\mathrm{neg}},\, H_{\mathrm{neg}},\, H_{\mathrm{pos}})
\]
with the same contrastive function $\mathrm{CTR}$ and temperature $\tau = 0.1$ as in TruthX. This term forces the SLiM-modulated representations to cluster truthful samples together and separate them from hallucinated ones in the hidden space.

\paragraph{Regularization Loss ($\mathcal{L}_{\mathrm{Reg}}$).}
An L2 penalty on the scale and shift activations to keep the modulation close to identity and avoid degenerate generations:
\[
\mathcal{L}_{\mathrm{Reg}} = \|\boldsymbol{\gamma}\|_2^2 + \|\boldsymbol{\beta}\|_2^2
\]

\subsubsection{Training Procedure}

The training procedure processes paired batches of (positive, negative) samples. For each batch:
\begin{enumerate}
    \item A \textbf{forward pass} is performed on positive samples with state $s = 1.0$; the SLiM hook captures the modulated hidden state and the model produces logits for CE loss.
    \item A second forward pass is performed on negative samples with the same state $s = 1.0$; the hook captures the modulated hidden state.
    \item The \textbf{last-token representations} are extracted from both passes for the InfoNCE loss.
    \item The three loss components are combined and back-propagated; gradients flow only through the SLiM parameters (scale, shift, state projector), while the base model remains frozen.
\end{enumerate}

The dataset is split into 80\% training and 20\% validation with a fixed random seed. The optimizer is \textbf{AdamW} with a \textbf{linear schedule with warmup}. Early stopping on validation loss (hybrid objective) with configurable patience prevents overfitting. Gradient accumulation and gradient clipping (max norm 1.0) are used for stable training with small batch sizes.

\subsubsection{Inference-Time Modulation}
\label{sec:slim-inference}

During inference, the trained SLiM modules are loaded from a checkpoint and a \textbf{forward hook} is registered on the target transformer layer. When the forward pass reaches the target layer and produces the hidden state $\mathbf{h}$, the hook applies the FiLM modulation:
\begin{enumerate}
    \item The state vector $s = 1.0$ is projected: $\mathbf{p} = \mathrm{StateBlock}(s)$
    \item Scale and shift are computed: $\boldsymbol{\gamma} = \tanh(\mathrm{Scale}(\mathbf{p}))$, $\boldsymbol{\beta} = \tanh(\mathrm{Shift}(\mathbf{p}))$
    \item The modulation is applied: $\mathbf{h}' = \mathbf{h} + \alpha \cdot (\mathbf{h} \odot \boldsymbol{\gamma} + \boldsymbol{\beta})$
    \item The modulated $\mathbf{h}'$ replaces $\mathbf{h}$ and is passed to subsequent layers.
\end{enumerate}

The steering strength $\alpha$ can be tuned at inference time independently from the training value, allowing to explore the trade-off between hallucination reduction and fluency.


\subsubsection{Cross-Model SLiMTruth via Procrustes Alignment}

Analogously to TruthX (see Section above), SLiMTruth can be transferred to a different target model via Procrustes alignment. The procedure is identical to the one described for TruthX cross-model transfer, with a single difference in the \textbf{layer selection} step.

\paragraph{Layer Selection.}
While TruthX selects the target layer based on \textbf{probing accuracy} of the trained autoencoders across all virtual layers, SLiMTruth uses the \textbf{target layer from the SLiM training configuration} directly. Specifically:
\begin{enumerate}
    \item The \textbf{target module} (physical layer and type: attention/MLP/hidden) is read from the SLiM training config of the target model. This is the layer at which SLiM was trained and will be applied during inference.
    \item For each layer of the \textbf{trainer model} of the same module type, Linear CKA is computed against the target layer's activations on a shared set of instances, exactly as in TruthX.
    \item The trainer layer that \textbf{maximises CKA} is selected as the alignment anchor.
\end{enumerate}

\noindent Once the layer pair is determined, the Procrustes aligner fitting and the cross-model inference pipeline (pre-alignment $\to$ SLiM modulation $\to$ post-alignment) follow the exact same procedure described for TruthX cross-model transfer.

\paragraph{Cross-Model Inference.}
During inference on the target model, for each selected module:
\begin{enumerate}
    \item \textbf{Pre-alignment:} the target's activation $\mathbf{h}_{\mathrm{target}}$ is mapped into the trainer's space via $\tilde{\mathbf{h}} = \mathbf{h}_{\mathrm{target}}\,\mathbf{A}_{\mathrm{t \to tr}} + \mathbf{b}_{\mathrm{t \to tr}}$;
    \item \textbf{SLiM modulation:} the FiLM transformation is applied in the trainer's space:
    \[
    \tilde{\mathbf{h}}' = \tilde{\mathbf{h}} + \alpha \cdot \big(\tilde{\mathbf{h}} \odot \boldsymbol{\gamma} + \boldsymbol{\beta}\big)
    \]
    \item \textbf{Post-alignment:} the modulated activation is mapped back into the target's space: $\mathbf{h}'_{\mathrm{target}} = \tilde{\mathbf{h}}'\,\mathbf{A}_{\mathrm{tr \to t}} + \mathbf{b}_{\mathrm{tr \to t}}$.
\end{enumerate}
